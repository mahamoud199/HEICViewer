# HEIC Viewer Pro 📸

عارض صور احترافي فائق السرعة لنظام التشغيل **Windows 11 / 10** مخصص لفتح وعرض ومعالجة صور **HEIC / HEIF / AVIF** الناتجة عن أجهزة iPhone والهواتف والأنظمة الحديثة بجودتها الأصلية الكاملة وسرعة فائقة، مع التكامل التلقائي التام مع مستكشف ملفات ويندوز (Windows Explorer).

---

## 🌟 الميزات الرئيسية

- **عارض صور حقيقي متكامل**: يفتح الصور ويعرضها مباشرة وبسرعة فائقة عند النقر المزدوج على أي ملف `.heic` أو `.heif`.
- **أيقونة رسمية مخصصة للويندوز**: أيقونة متعددة الدقات (`16x16` إلى `256x256`) تظهر بدقة عالية في شريط العنوان وشريط المهام وسطح المكتب.
- **شريط المصغرات التفاعلي السفلي (Filmstrip)**: استعراض سلس لمصغرات صور المجلد الحالي أسفل الشاشة مع إمكانية إظهاره أو إخفائه (`T`).
- **عرض الشرائح التلقائي (Slideshow)**: استعراض تلقائي ذكي للصور بفاصل زمني أنيق (`F5` أو مسافة `Space`).
- **تعيين كخلفية لسطح المكتب (Desktop Wallpaper)**: تعيين أي صورة HEIC مباشرة كخلفية لويندوز بنقرة واحدة.
- **فتح في مستكشف الملفات (Show in Explorer)**: تحديد الصورة وموقعها فوراً داخل مجلدها الأصلي.
- **الحذف الآمن إلى سلة المحذوفات (Recycle Bin)**: حذف مباشر وآمن للملفات مع طلب تأكيد ودعم كامل للاسترجاع (`Delete`).
- **دعم الطباعة المباشرة (Print)**: نافذة حوار طباعة متكاملة للويندوز (`Ctrl + P`).
- **نسخ فوري إلى الحافظة (Clipboard)**: نسخ الصورة بضغطة زر للصقها في فوتوشوب أو أوفيس أو برامج المحادثة (`Ctrl + C`).
- **تصدير وتحويل فائق السرعة**: تحويل الصور إلى صيغ متعددة (PNG, JPG, WebP, BMP) مع التحكم بجودة الضغط.
- **دعم ميتاداتا الكاميرا (EXIF)**: استخراج تفاصيل الكاميرا، سرعة الغالق، العدسة، وحساسية ISO.
- **دعم الوضعين الفاتح والداكن (Fluent Dark/Light)**: واجهة أنيقة تتبع أفضل ممارسات تصميم ويندوز الحديثة.

## 🛠️ هيكل المشروع البرمجي (Modular Architecture)

```
HEICViewer/
├── main.py                    # نقطة الدخول الرئيسية للبرنامج ومعالجة معاملات سطر الأوامر
├── requirements.txt           # متطلبات ومكتبات المشروع
├── README.md                  # الدليل الشامل والمفصل
├── .gitignore                 # استبعاد مخرجات البناء والملفات المؤقتة
│
├── app/                       # واجهة المستخدم والمكونات الرسومية (PySide6)
│   ├── __init__.py
│   ├── main_window.py         # النافذة الرئيسية والتنقل ومعالجة السحب والإفلات
│   ├── image_view.py          # لوحة العرض التفاعلية (Zoom, Pan, Rotate, Flip, Fit)
│   ├── filmstrip.py           # شريط المصغرات السفلي التفاعلي السريع (Safe QThread & Signals)
│   ├── toolbar.py             # شريط الأدوات الرئيسي مع كافة الأيقونات الفيكتور
│   ├── icon_helper.py         # محرك تحميل وتلوين أيقونات SVG بجودة Retina/High-DPI
│   ├── resource_helper.py     # إدارة وتحديد مسارات الأيقونات والموارد
│   └── settings.py            # إدارة الإعدادات والسمات (Light & Dark Themes)
│
├── services/                  # الخدمات ومعالجة المنطق الخلفي
│   ├── __init__.py
│   ├── image_loader.py        # فك تشفير صور HEIC وكاش الذاكرة وقفل التزامن
│   ├── image_converter.py     # تحويل وتصدير الصور إلى PNG, JPG, WebP, BMP
│   ├── file_association.py   # إدارة سجل ويندوز (Registry) وربط الامتدادات
│   └── thumbnail_cache_helper.py # مسرع كاش المصغرات لويندوز
│
├── assets/                    # الأيقونات والموارد
│   ├── app.ico                # أيقونة التطبيق متعددة الأحجام لشريط العنوان والمهام
│   ├── app_icon.png           # الشعار الرسومي عالي الدقة
│   └── icons/                 # أيقونات SVG فيكتور للواجهة وشريط الأدوات
│
├── installer/                 # إعدادات حزمة التثبيت
│   └── setup.iss              # سكربت Inno Setup لتوليد ملف التثبيت HEICViewer-Setup.exe
│
└── tests/                     # الاختبارات الآلية
    ├── test_heic.py           # اختبارات قراءة وتصدير صور HEIC ومعالجة الملفات التالفة
    ├── test_file_opening.py   # اختبارات تكامل ويندوز والارتباطات
    └── test_features.py       # اختبارات سلامة الأيقونة وشريط المصغرات
```

## ⚡ طرق التشغيل والتثبيت

### 1. التثبيت المباشر بنقرة واحدة
قم بتشغيل ملف التثبيت المولد:
```
HEICViewer-Setup.exe
```
يقوم المثبّت بـ:
- تثبيت البرنامج في مجلد البرامج الرسمي (`Program Files (x86)\HEIC Viewer`).
- إنشاء اختصارات في قائمة ابدأ وسطح المكتب.
- **تسجيل امتدادات `.heic` و `.heif` تلقائياً** ليصبح التطبيق هو العارض المباشر عند النقر المزدوج على أي صورة.
- توفير برنامج إلغاء تثبيت نظيف (Uninstaller).

### 2. التشغيل من الكود المصدري (للمطورين)
```bash
# تثبيت المتطلبات
pip install -r requirements.txt

# تشغيل البرنامج
python main.py

# أو تمرير صورة مباشرة
python main.py "path/to/photo.heic"
```

### 3. تشغيل الاختبارات الآلية
```bash
pytest tests/ -v
```

## ⌨️ جدول الاختصارات السريعة

| الاختصار | الوظيفة |
| :--- | :--- |
| `Ctrl + O` | فتح صورة جديدة من المستكشف |
| `Ctrl + S` | تصدير / حفظ الصورة بصيغة أخرى (PNG, JPG, WebP, BMP) |
| `Ctrl + C` | نسخ الصورة الحالية مباشرة إلى الحافظة (Clipboard) |
| `Ctrl + P` | طباعة الصورة الحالية مباشرة |
| `Delete` | نقل الصورة الحالية بأمان إلى سلة المحذوفات |
| `F5` / `Space` | تشغيل / إيقاف عرض الشرائح التلقائي (Slideshow) |
| `T` | إظهار / إخفاء شريط المصغرات السفلي (Filmstrip) |
| `السهم الأيمن` | الانتقال للصورة التالية في المجلد |
| `السهم الأيسر` | الانتقال للصورة السابقة في المجلد |
| `+` / `عجلة الماوس للأعلى` | تكبير الصورة بدقة عند موضع المؤشر |
| `-` / `عجلة الماوس للأسفل` | تصغير الصورة |
| `1` | الحجم الفعلي 100% |
| `0` | ملاءمة الصورة مع حجم النافذة |
| `L` / `Ctrl + L` | تدوير 90 درجة لليسار |
| `R` / `Ctrl + R` | تدوير 90 درجة لليمين |
| `H` | قلب الصورة أفقياً (Flip Horizontal) |
| `Ctrl + I` | عرض تفاصيل الكاميرا والميتاداتا (EXIF) |
| `F11` أو نقر مزدوج | التبديل بين وضع ملء الشاشة والوضع الطبيعي |
| `Esc` | الخروج من وضع ملء الشاشة أو إغلاق النوافذ المنبثقة |
